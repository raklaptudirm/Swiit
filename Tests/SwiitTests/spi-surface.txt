# The core's SPI: each `@_spi(G) public` declaration in Sources/Swiit, as
# file<TAB>group kind name, checked by theCoresSPIOnlyShrinks. The groups are
# by purpose: Host, what any host needs (the candidates for public API);
# Layer, what a syntax layer like the shell's builds on (the tree, the parser,
# the checker); Internals, the evaluator's insides, which a layer should come
# to need less; Swiit, what only the core's own other modules use. A new line
# is a decision; a line goes when its declaration becomes public API or
# internal (Docs/Design/extraction.md, stages 1 and 2). Overloads repeat
# their line.
